# Submission steps (for you)

1. Copy `.env.example` → `.env` and set `GROQ_API_KEY`.
2. `npm install` && `npm run dev`
3. Upload the three PDFs in `starter-datasets/` and wait until status is `ready`.
4. Confirm Demo Cases shows corroboration / contradiction / reconciled / failure.
5. Record a ≤3 min Loom/YouTube video (script in `docs/DEMO_CASES.md`).
6. Put the video URL in `README.md` under **Video Demo**.
7. Create a GitHub repo, push `main`, ensure it is public (or accessible to Superjoin).
8. Submit https://forms.gle/3fLdBQ2D6Zm2Gqtv7 with repo + video links.
